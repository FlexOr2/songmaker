The rail leads: one album list, no row

Albums live in the rail: instant filter, cover tile, kinetic vertical scrolling, and a remembered detail level. The centre names the place and holds the work. On Library, the wall remains the large view; it does not duplicate the rail.

Ruling #564: One rail. Settings keeps the same rail; only the content changes. List is the default. Covers and Narrow change the rail’s detail, never the navigation model. Its width is remembered per browser and can be dragged from 220 to 360 px.
