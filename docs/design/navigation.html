One frame from album to song to take

The album row stays above the editor when a person opens a song or take. It uses the same instant filter, album tiles, open marking, and collapse control as the album view. On a 375 px screen it starts collapsed, leaving the Takes bar clear.

Ruling #545: the row remembers its collapsed state per browser, like Now Playing. Settings is the one exception: it keeps the shared frame but has no album row.
