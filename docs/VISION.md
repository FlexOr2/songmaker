# Songmaker vision

**Status: non-normative overview.** Approved product truth will live only in the
active tips of the [requirement registry](requirements/revisions.toml). This
page does not approve or replace a requirement.

Songmaker is a music-making workspace in which a musician organizes albums and
songs, writes lyrics and style prompts, generates multiple audio takes, and
listens to the results. Songs keep immutable versions of their creative input;
generations keep the resulting audio. A pick identifies the album take, while
keeps preserve any additional favourites.

This summary restates the current product description in the repository
[README](../README.md) and the domain model in [CLAUDE.md](../CLAUDE.md). Those
documents describe the running system; future normative intent requires the
approval lifecycle below.
